How it works

The hosting computer runs a small web service. You open it from any browser on the allowed network, enter the target and an admin account, pick tasks and press Run. Output streams back live.

1 · Connect

Hostname/IP, user (DOMAIN\user or user@domain), password and a transport. “Test Connection” checks DNS, WinRM and your credentials.

2 · Choose tasks

Tabs by category, one card per operation. Operations that need input (an IP, an adapter, a share path…) show validated fields. Sensitive ones are amber with “!”.

3 · Run & watch

Live, colour-coded output with a progress bar and a Stop button. Every run ends with a tally and a log file saved on the hosting machine.

What it can do

Everything below is in the live demo.

113 operations, 9 categories

Cleanup · Disk · Performance · Windows Health · Network · Power Recycle · Remote Tools · Admin Consoles · Network Push. Browse them all below.

Network Push v4.0

Set a static IP, DHCP, flush DNS, reset TCP/IP or restart adapters by pushing the command and not waiting — the right design when the change itself cuts the connection. IP, mask, gateway and both DNS servers go in one command, after a read-only pre-check that refuses typos.

Ping Monitor v4.0

Pings the host name and up to two IPs every second until you press Stop and shows which IP is answering — watch the old address go silent and the new one come alive, with WinRM reachability and DNS catch-up.

Verified network changes v3.8

The classic network operations check what Windows really did and end with SUCCESS / WARNING / FAILED. An auto-rollback restores the old settings if the tool can no longer reach the PC.

Input validation

Every parameter has an allow-listed format (IPv4, subnet mask, computer name, adapter, service, UNC path, drive, VSS size, user account…). Checked in the browser for instant feedback and again on the server.

Sensitive-operation gate

Risky operations are amber with “!” and need a confirmation. The server also refuses them unless the request carries explicit confirmation, so a hand-made request can't skip the popup.

Long jobs that survive

Slow or connection-dropping operations run as background jobs on the target, with several launch fallbacks, a hard time limit and a heartbeat so a running job is never mistaken for a dead one.

26 admin consoles

Open Computer Management, Device Manager, Event Viewer, Services, Regedit, an elevated PowerShell and more on the user's screen — handy for walking someone through a fix.

Logs & tallies

Each run writes a timestamped log on the hosting machine and ends with “N succeeded, N warning, N failed”. Stop ends a run cleanly at any point.

Run the real thing

Full step-by-step instructions for non-technical users are in the Setup & User Guide in the repository. The short version:

1 · On the target PC (once)

Turn on WinRM in an elevated PowerShell:

Enable-PSRemoting -Force

You need an administrator account on the target.

2 · On the hosting PC

Web edition: install Python, then:

pip install -r requirements.txt
python app.py

Open http://<hosting-PC-IP>:3030. On Windows you can also use install_service.bat to run it as a service.

Good to know before you deploy

  • The tool talks WinRM over HTTP (port 5985). NTLM, Kerberos and CredSSP protect the messages themselves; Basic does not — use it only on a network you trust.
  • Anyone on the allowed subnet who can reach port 3030 can open the web UI, so run it on a trusted management network and restrict who can reach it.
  • Logs are written on the hosting machine, not in the browser.

Version history

Highlights from the project's changelog.

v4.0 — Network Push & Ping Monitor

The v16 “push and don't wait” method, done right, plus a continuous ping with live “which IP answers” view. New 9th category; 113 operations.

v3.9 — launcher fallbacks

When Windows refused the SYSTEM scheduled task (0x80070005), background jobs now fall back to a CIM process, then to a direct in-session run; heartbeat added.

v3.8 — verified network operations

RESULT lines (SUCCESS / WARNING / FAILED), one-shot IP+mask+gateway+DNS apply, auto-rollback, hard job time-out, fixed port 3030.

v3.7 — resilient jobs & new tools

Detached jobs for network and long operations, domain-safe computer rename, VSS sizing, DISM and WMI tools, performance-counter rebuild, SSD retrim.
